# Issue
环境：Ubuntu 22.04，greetlab项目
复现命令：sdt‑greet --name "   "
期望结果：检测全空白名称，程序以退出码2终止
实际结果：输出 Hello, !，程序正常退出
未知信息：待确认

# 提交信息
fix: 拦截仅含空白字符的name输入
当--name传入全空格字符串时，经过strip校验识别空输入，调用sys.exit(2)终止程序，拒绝无效名称。

# 评审意见
行为：现有代码未校验name参数全空白场景，空白输入仍可正常输出问候。
风险：外部调用会得到无意义输出，违反接口约定。
建议动作：参数读取后增加strip空值判断，全空白输入返回退出码2。
